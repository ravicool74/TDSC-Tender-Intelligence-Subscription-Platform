📡 Razorpay Webhook Configuration Guide (स्वचालित भुगतान रसीद सेटअप)

Jab customer payment complete karega to Razorpay aapke server par turant cryptographic webhook bhejega. Setup nirdesh:

  1. Apne Razorpay Dashboard → Settings → Webhooks par jayein.
  2. Add New Webhook par click karein.
  3. Webhook URL: http://localhost:8000/api/payments/webhook
  4. Secret: Jo Secret aapne upar Webhook Secret field me daala hai wahi yahan darj karein.
  5. Active Events select karein: payment.captured, payment.failed, refund.processed
  6. Save karein! Webhook verification HMAC-SHA256 signature dwara verified aur idempotent hai.
